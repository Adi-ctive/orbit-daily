# Decisions

Choices made where the build prompt left room. Newest at the bottom.

## Phase 1

- **Project folder:** `C:\projects\orbit`. The prompt and research live in `docs/`.
- **Versions:** Vite 8, Svelte 5.57, TypeScript 6, vite-plugin-pwa 2, Vitest 5, ESLint 10 (flat config), Playwright 1.64.
- **Dev panel gate:** a compile-time `__DEV_PANEL__` flag. It is `false` in `vite build` (production mode), so the panel code is removed. `vite build --mode e2e` keeps it for Playwright runs. At runtime it also needs `?dev=1`.
- **Dev date override:** an offset on `appClock`, so every time read goes through one place.
- **Storage:** `idb-keyval` with one store (`orbit-db/kv`). If IndexedDB is missing or throws, it falls back to an in-memory map, so a round never crashes. Every call is wrapped in try/catch.
- **Math.random ban:** `no-restricted-properties` in ESLint, turned off only for `src/lib/rng.ts`.
- **RNG:** sfc32 seeded by xmur3, with the first 12 outputs discarded. `fork(label)` gives each game its own stable stream from the day seed.
- **Icons:** generated by `scripts/make-icons.mjs` (pure Node, no image libs) as a dithered ringed planet on a 32 px grid, scaled by an integer factor.
- **npm audit:** the open advisories (deepmerge, glob) are in build-time dependencies of vite-plugin-pwa and the Svelte plugin. None ships to the browser. Revisit when upstream updates.

## Known limits (accepted for v1)

- The daily lock is client-side only. A determined user can bypass it by moving the device clock forward or clearing site data. Clearing data also wipes their streak, which is deterrent enough. `src/lib/clock.ts` hides time behind a `Clock` interface so a free Cloudflare Worker time check can be added later.
