# ORBIT

Fifteen minutes. One mission. Every day.

A free daily brain-training and STEM mission with cosmic pixel art. One button starts about 15 minutes of seeded puzzles, mini-games and one learning card. Then it locks until local midnight. No ads, no accounts, no payments.

## Install on Android

Open link in Chrome → ⋮ → Add to Home screen.

## Develop

```bash
npm install
npm run dev
```

Add `?dev=1` to the URL in dev builds for the dev panel (change date or seed, skip rounds, unlock).

## Checks

```bash
npm run lint && npm run typecheck && npm test
```

See `docs/DECISIONS.md` for choices made during the build.
